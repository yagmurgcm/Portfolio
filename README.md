# Yağmur Geçim · Interactive Portfolio

**Play it:** https://yagmurgcm.github.io/portfolio/

A CV you can explore. It is late at night in a lamp-lit study room, and every object on the desk, the shelves and the corkboard opens a chapter of my story: internships, research, and projects in AI, data, systems and games.

- 19 inspectable objects, each tied to a real experience or project
- Quest log for internships, a skills tree that unlocks as you explore, and a one-click Quick CV
- Procedural lo-fi soundtrack and ambience built with the Web Audio API
- English and Turkish
- A single self-contained HTML file: hand-drawn SVG scene, vanilla JavaScript, no build step
